Contactez l'Agence du revenu du Canada (ARC)

Aide concernant les sujets les plus fréquents

Réponses aux questions les plus fréquentes

  • Accéder à un compte de l'ARC

    Quel est votre problème?

    J'ai un problème concernant mon code de sécurité de l'ARC

    Si vous avez perdu votre code de sécurité de l’ARC ou s’il n’est pas arrivé après 10 jours ouvrables, vous pouvez plutôt utiliser le service de vérification des documents pour faire vérifier votre identité.

    Pour utiliser le service de vérification des documents :

    1. Allez à la page Se connecter à son compte de l’ARC et commencez à vous connecter.
    2. Suivez les étapes de sécurité et d’authentification multifacteur.
    3. Lorsqu’on vous demandera d’entrer votre code de sécurité, choisissez le service de vérification des documents.

    Pour en savoir plus, consultez Vérification de votre identité.

    Si votre code de sécurité de l’ARC est expiré

    Si votre code de sécurité de l’ARC est expiré, utiliser le service de vérification des documents est la façon la plus rapide de faire vérifier votre identité. Une autre méthode consiste à demander qu’un nouveau code de sécurité de l’ARC vous soit envoyé par la poste.

    1. Allez à la page Se connecter à son compte de l’ARC et commencez à vous connecter.
    2. Suivez les étapes de sécurité et d’authentification multifacteur.
    3. Lorsque vous recevrez le message d’erreur indiquant que votre code de sécurité est expiré, choisissez Code de sécurité de l’ARC en ligne ou le service de vérification des documents.

    Pour en savoir plus, consultez Vérification de votre identité.

    Si vous avez perdu votre code et que vous ne pouvez pas utiliser le service de vérification de documents

    Vous devrez appeler l'ARC pour recevoir un autre code de sécurité de l'ARC par la poste.

    Avant d'appeler :

    1. Ayez en main vos documents d'impôt pour valider votre identité.
    2. Composez le 1-800-959-7383.
    3. Choisissez l'option 1 pour les services en ligne.
    Je n’ai pas reçu mon code d’accès à utilisation unique pour l’authentification multifacteur

    Si vous n'avez pas reçu votre code d'accès à utilisation unique, vous pouvez prendre l’une des mesures suivantes :

    • Utiliser l'application d'authentification tierce si elle est déjà configurée
    • Demander qu'il soit envoyé ou renvoyé à un autre numéro de téléphone qui est déjà inscrit à votre compte
    • Essayer l'option Appelez-moi au lieu d’Envoyez-moi un message texte si vous utilisez un service VoIP
    • Utiliser la grille de codes d'accès si vous êtes déjà inscrit à cette option

    Pour en savoir plus : Authentification multifacteur

    Si votre numéro de téléphone a récemment changé

    Si votre numéro de téléphone a changé et que vous ne pouvez plus recevoir votre code d’accès à utilisation unique à ce numéro, vous pouvez utiliser une autre option d’authentification multifacteur si vous êtes déjà inscrit à cette option.

    Si vous ne pouvez toujours pas recevoir votre code d’accès à utilisation unique, vous devrez nous contacter.

    Avant d'appeler :

    1. Ayez en main vos documents d'impôt pour valider votre identité.
    2. Composez le 1-800-959-7383.
    3. Choisissez l'option 1 pour les services en ligne.
    Je ne me souviens plus de mon ID utilisateur ou de mon mot de passe de l'ARC

    Vous pouvez récupérer votre ID utilisateur ou votre mot de passe de l'ARC en ligne.

    Pour récupérer votre ID utilisateur
    1. Allez à la page Se connecter à son dossier de l’ARC.
    2. Choisissez ID utilisateur et mot de passe de l'ARC dans les options de connexion.
    3. Choisissez Vous avez oublié votre ID utilisateur?
    4. Fournissez les renseignements suivants :
      • Votre numéro d'assurance sociale (NAS)
      • Votre date de naissance
      • Une copie de votre déclaration de revenus des particuliers de cette année ou de l'année dernière ayant fait l'objet d'une cotisation
    5. Les réponses aux questions de sécurité que vous avez choisies lors de l'inscription
    Pour récupérer votre mot de passe
    1. Allez à la page Se connecter à son dossier de l’ARC.
    2. Choisissez ID utilisateur et mot de passe de l'ARC dans les options de connexion.
    3. Choisissez Vous avez oublié votre mot de passe?
    4. Entrez votre ID utilisateur.
    5. Répondez aux questions de sécurité que vous avez choisies lors de l'inscription.
    Si vous ne pouvez toujours pas récupérer votre ID utilisateur ou votre mot de passe

    Si vous avez perdu l’accès à votre compte de l’ARC, vous pourriez le récupérer en repassant par le processus d’inscription.

    Récupérer l’accès à votre compte de l’ARC

    Vous pourriez être en mesure de récupérer l’accès à votre compte de l’ARC à l’aide de nouvelles informations de connexion si :

    • vous avez oublié votre ID utilisateur ou mot de passe de l’ARC
    • vous avez oublié les réponses à vos questions de sécurité
    • vos justificatifs d’identité ont été révoqués

    Vous devrez être en mesure :

    • d’utiliser l’option d’authentification multifacteur que vous avez choisie initialement
    • de terminer le processus d’inscription, y compris la vérification de l’identité

    Tous les anciens ID utilisateur et mots de passe de l’ARC, ainsi que tous les anciens partenaires de connexion liés à votre compte de l’ARC seront supprimés. Les justificatifs d’identité des partenaires provinciaux ne seront pas supprimés au cours de ce processus.

    Vous ne pouvez pas suivre le processus d’inscription pour récupérer votre compte si votre compte a été verrouillé par l’ARC pour des raisons de sécurité ou toute autre raison.

    Pour en savoir plus, consultez S'inscrire à un compte de l'ARC.

    Si vous avez essayé de vous inscrire à nouveau et que vous ne pouvez toujours pas accéder à votre compte, contactez-nous
    1. Ayez en main vos documents d'impôt pour valider votre identité.
    2. Composez le 1-800-959-7383.
    3. Choisissez l'option 1 pour les services en ligne.
    J'ai de la difficulté à utiliser mon partenaire de connexion

    Contactez votre institution financière si vous rencontrez des problèmes avec vos informations de connexion.

    Pour changer de partenaire de connexion

    Vous pouvez changer pour un autre partenaire de connexion en tout temps si vous avez toujours accès au partenaire de connexion que vous utilisiez auparavant :

    1. Allez à la page Se connecter à son dossier de l’ARC.
    2. Choisissez Partenaire de connexion.
    3. Choisissez Changer mon partenaire de connexion en haut de la page.
    4. Suivez les instructions.
    Si vous ne pouvez pas accéder à votre ancien partenaire de connexion

    Si vous avez perdu l’accès à votre compte de l’ARC, vous pourriez le récupérer en repassant par le processus d’inscription.

    Récupérer l’accès à votre compte de l’ARC
    Si vous avez essayé de vous inscrire à nouveau et que vous ne pouvez toujours pas accéder à votre compte, contactez-nous
    1. Ayez en main vos documents d’impôt pour valider votre identité.

    Mon compte est verrouillé

    Si vous recevez un message d’erreur indiquant que votre compte est verrouillé, suivez les instructions fournies dans le message.

    Si vous avez perdu l’accès à votre compte de l’ARC, vous pourriez le récupérer en repassant par le processus d’inscription.

    Je dois m'inscrire à un compte de l’ARC

    Si vous n'avez pas de compte de l'ARC, vous pouvez vous inscrire. Cela vous donnera accès à Mon dossier et vous donnera la possibilité d’ajouter Mon dossier d’entreprise ou Représenter un client.

    1. Inscrivez-vous à un compte de l’ARC et accédez à votre compte Particulier.
    2. Ajoutez un compte Entreprise (facultatif)
    3. Ajoutez un compte Représentant (facultatif)

    Si votre accès est limité, vous devrez valider votre code de sécurité, ce qui vous donnera un accès complet et vous permettra d’ajouter un autre compte.

  • Si vous n’êtes pas en mesure de nous joindre par téléphone

    Nous dirigeons certains appels à la ligne téléphonique automatisée

    En raison du volume élevé d’appels, il se peut que nous dirigions votre appel vers la ligne téléphonique automatisée. Nous essayons de maintenir le temps moyen d’attente à environ 30 minutes.

    Ce que vous pouvez faire à l’aide de la ligne automatisée

    Vous pouvez prendre les mesures suivantes à l’aide la ligne téléphonique automatisée :

    • Vérifier l’état de votre déclaration de revenus
    • Obtenir une estimation du montant de votre remboursement
    • Vérifier le solde de votre compte de l’ARC

    Il est possible d’utiliser la ligne téléphonique automatisée toute la journée, sauf de 3 h à 6 h (HE).

    Essayez d’appeler à un autre moment

    Si vous n’êtes pas en mesure de répondre à vos préoccupations à l’aide de la ligne automatisée, essayez de rappeler à l’un de ces moments :

    • À un autre moment de la journée
    • Un autre jour de la semaine

    Vérifiez si un représentant est disponible

    • Si un temps d’attente est fourni, des représentants du service sont disponibles.
    • Si le temps d’attente est « Non disponible », votre appel sera dirigé vers la ligne automatisée.

    Trouvez un numéro et rappelez

    Les heures de service de l’ARC sont indiquées selon l’heure de l’Est.

    Essayez d’utiliser d’autres ressources en ligne de l’ARC

    Vous pouvez aussi trouver l’information dont vous avez besoin en ligne.

    • Consultez les autres « sujets fréquents » sur cette page.
    • Connectez-vous à votre compte de l’ARC pour vérifier votre compte Particulier, Entreprise ou Représentant.
    • Trouvez les formulaires dont vous avez besoin en consultant commander de formulaires et de publications.
    • Clavardez avec un représentant en direct au moyen du clavardage en ligne dans votre compte de l’ARC (Particulier).
    • Passez en revue les sujets sur les pages Web de l’ARC.
  • Déterminer pourquoi il vous manque un paiement de prestation

    Raisons pour lesquelles les paiements de prestation peuvent cesser

    Vos paiements pourraient cesser si vous n'avez pas :

    • produit votre déclaration de revenus
    • répondu à une lettre de l'ARC concernant votre situation
    • informé l'ARC d'un changement concernant :
      • Votre adresse
      • Vos renseignements bancaires
      • Votre état civil
      • La garde de vos enfants

    Vos paiements pourraient cesser si votre époux ou conjoint de fait n'a pas :

    • produit sa déclaration de revenus
    • informé l'ARC d'un changement concernant :
      • Son état civil
      • La garde de ses enfants

    Vérifier les renseignements liés à votre prestation

    Vérifiez votre compte de l'ARC pour vous assurer que tous vos renseignements sont à jour.

    1. Connectez-vous à votre compte de l’ARC.
    2. Choisissez votre compte Particulier.
      • Ouvrez votre Courrier pour voir si vous avez des communications en suspens.
      • Passez en revue votre Profil pour vous assurer qu’il est à jour.
      • Vérifiez les Prestations et crédits pour voir l’état de vos prestations.

    Vérifiez les dates auxquelles les prestations de l'ARC sont versées : Dates de versement des prestations

    Pour en savoir plus sur ce qui peut avoir des conséquences sur certains paiements spécifiques :

    • Crédit pour la TPS/TVH : Montant que vous pouvez vous attendre à recevoir
    • Allocation canadienne pour enfants : Continuer à recevoir vos versements
    • Remise canadienne sur le carbone : Quand vous attendre à recevoir vos versements

    Modifier les renseignements de votre entreprise

    Modifiez vos renseignements d'entreprise dans votre compte de l'ARC.

    1. Connectez-vous à votre compte de l’ARC.

    3. Allez à Profil pour changer les renseignements suivants :
      • Adresse d'entreprise
      • Dépôt direct et renseignements bancaires
      • Nom commercial

    Pour en savoir plus, consultez Changements effectués à votre entreprise et à vos comptes de programme de l'ARC.

  • Vérifier l'état de votre remboursement d'impôt

    La façon dont vous produisez votre déclaration de revenus des particuliers peut avoir une incidence sur le moment où vous recevez votre remboursement.

    Délais de traitement standards

    L'ARC vise à vous envoyer un avis de cotisation, ainsi que tout remboursement, dans les délais suivants :

    • Déclaration produite en ligne : 2 semaines
    • Déclaration papier envoyée par la poste : 12 semaines
    • Déclaration des non-résidents : 16 semaines 

    Ces délais s'appliquent seulement aux déclarations que nous recevons au plus tard à la date limite.

    Vérifier l'état de votre déclaration

    Vous pouvez vérifier l'état de votre déclaration en ligne à l'aide de votre compte de l'ARC.

    1. Connectez-vous à votre compte de l’ARC.
    2. Choisissez votre compte Particulier.

    Pour les autres options : Vérifiez l'état de votre déclaration

    Raisons pour lesquelles vous n'avez peut-être pas reçu votre remboursement

    Si vous avez une autre dette envers le gouvernement, l'ARC pourrait garder la totalité ou une partie de votre remboursement.

    Comment les prestations et les crédits peuvent être appliqués à votre dette envers le gouvernement

  • Renseignez-vous sur l’Allocation canadienne pour l’épicerie et les besoins essentiels ainsi que sur le versement supplémentaire unique du crédit pour la TPS/TVH

    Les montants des versements de l’Allocation canadienne pour l’épicerie et les besoins essentiels et du versement supplémentaire unique du crédit pour la TPS/TVH sont calculés en fonction des éléments suivants :

    • Votre revenu familial net rajusté
    • Votre état civil
    • Le nombre d’enfants admissibles de moins de 19 ans

    Allocation canadienne pour l’épicerie et les besoins essentiels

    l’Allocation canadienne pour l’épicerie et les besoins essentiels remplacera le crédit pour la TPS/TVH en juillet 2026. L’admissibilité et la structure de l’allocation seront les mêmes que celles du crédit pour la TPS/TVH.

    Si vous et votre époux ou conjoint de fait avez produit votre déclaration de revenus de 2025 à temps et que vous y avez droit, les montants commenceront à être versés en juillet 2026 en vertu du nouveau nom de l’allocation.

    Pour connaître le montant des versements ou savoir pourquoi vous ne recevez pas de versement, consultez Allocation canadienne pour l’épicerie et les besoins essentiels.

    Versement supplémentaire unique du crédit pour la TPS/TVH

    Le versement supplémentaire unique du crédit pour la TPS/TVH offre un soutien immédiat avant que la nouvelle Allocation canadienne pour l’épicerie et les besoins essentiels remplace le crédit pour la TPS/TVH en juillet 2026.

    Si vous avez produit votre déclaration de revenus de 2024 et que vous aviez droit à un versement du crédit pour la TPS/TVH en janvier 2026, le versement supplémentaire vous sera envoyé à partir du 5 juin 2026.

    Pour connaître le montant du versement ou savoir pourquoi vous ne le recevez pas, consultez Versement supplémentaire unique du crédit pour la TPS/TVH.

Avis de confidentialité

Avis de confidentialité

Les centres d'appels de l'Agence du revenu du Canada (ARC) enregistrent certains appels. Ces enregistrements d'appels sont utilisés pour évaluer la qualité et l'exactitude des réponses des agents, identifier les tendances des appels et donner un aperçu des domaines potentiels dans lesquels une formation serait bénéfique. L'enregistrement débute à partir du moment où un agent répond à l'appel et se poursuit jusqu'à ce que la ligne soit déconnectée, y compris tout le temps passé en attente.

Si vous ne souhaitez pas que votre appel soit enregistré, veuillez en informer l'agent au début de l'appel.

Lors de votre conversation avec un agent et lors de l'utilisation des options de libre-service automatisées, il peut vous être demandé de fournir des informations personnelles afin de valider votre identité. Les questions posées sont en place pour assurer la sûreté et la sécurité de votre compte. Sans cette étape de vérification, l'ARC n'est pas en mesure d'accéder à vos renseignements de compte ou d'apporter des modifications.

Les renseignements personnels sont recueillis conformément à la Loi de l'impôt sur le revenu et à la Loi sur la taxe d'accise. Les renseignements personnels sont décrits dans des fichiers de renseignements personnels propres au programme qui se trouvent sur la page Renseignements sur les programmes et les fonds de renseignements (anciennement Info Source) de l'ARC.

En vertu de la Loi sur la protection des renseignements personnels, les individus ont un droit de protection, d'accès et de correction ou de notation de leurs informations personnelles. Les particuliers ont également le droit de déposer une plainte auprès du Commissaire à la protection de la vie privée du Canada concernant la façon dont nous traitons leurs renseignements.

Communications par courriel

Pour protéger la sécurité de vos renseignements, nous communiquons par courriel seulement dans des situations précises. Vous ne pouvez pas nous contacter par courriel pour des questions générales liées à l'impôt.

Vous ne devriez jamais envoyer de renseignements confidentiels dans un courriel, comme votre numéro d’assurance sociale (NAS) ou des informations sur votre déclaration de revenus.
